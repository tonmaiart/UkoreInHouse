# Project Editor
![Project Editor](../assets/images/ukhub_project_editor.png)


เป็นหน้าสำหรับเลือก Repositories ที่เราจะทำงาน โดยแต่ละ Repositories ก็จะแบ่งแยกไปตามลักษณะงาน เช่น Animator ก็จะทำงานใน Repo ที่ชื่อAnimatorTeam , ฝ่าย Assets ก็จะทำงานใน Repo ที่ชื่อ AssetTeam เป็นต้น

# Program Launcher
![Explorer](../assets/images/ukhub_program_launcher.png)
