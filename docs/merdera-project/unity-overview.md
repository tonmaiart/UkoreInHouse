ใน Merdera Project เราตัดสินใจให้นำฉาก , Props ทั้งหมดไป Build , Composite , Render ไปที่โปรแกรม Unity
ด้วยเหตุผลทั้งข้อดีและข้อจำกัดดังนี้

**ข้อดี**

1. Unity รองรับการนำเข้า Assets จำนวนมหาศาล

2. Unity มีระบบ Prefabs ที่ทรงพลัง ทำให้การแก้ไขทำได้ง่าย (Non Destructive)

3. Unity Render แบบ Realtime ได้ ทำให้ไวกว่า Maya มหาศาล

4. Unity สามารถทำ VFX ที่ stylized style ได้อย่างง่ายได้และเหมาะสมกับแนวทางของ Merdera Project

**ข้อจำกัด**

1. เนื่องจาก Unity เป็น Game Engine ทำให้ต้องปรับปรุง Rig และวิธี Import ให้รองรับกับข้อกำหนดของ Program Unity อย่างเคร่งครัด เพื่อรักษาผลลัพธ์ของ Animation ให้เป็นไปตามที่คาดหวังไว้

2. ระบบ Pipeline จาก Maya ไป Unity ต้องถูกวางแผนมาอย่างดี มีความเสถียรมากพอ และหมั่นทดสอบในทุกแง่มุมตั้งแต่เนิ่นๆ เพื่อไม่ให้เกิด Overload ในช่วงท้ายของโปรเจค

3. การเขียน Custom Shader ใน Unity ต้องมีการเขียนโค้ดเพื่อแก้ไขปรับปรุง
